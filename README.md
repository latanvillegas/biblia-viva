# Biblia Viva

**La Palabra contigo.**

Biblia Viva es una aplicación móvil de lectura y estudio bíblico, con una experiencia moderna y una identidad propia.

## Objetivo

Construir una aplicación para Android y iOS que permita leer la Biblia, buscar pasajes, guardar favoritos, crear notas y seguir planes de lectura.

## MVP

- Inicio y versículo del día
- Navegación por libros, capítulos y versículos
- Búsqueda bíblica
- Favoritos y resaltados
- Notas personales
- Planes de lectura
- Perfil y preferencias
- Modo claro/oscuro
- Arquitectura preparada para audio y sincronización

## Tecnología propuesta

- React Native
- Expo
- TypeScript
- Expo Router

## Contenido bíblico

Las traducciones bíblicas se integrarán como fuentes de contenido independientes. Solo se incorporarán textos de dominio público o traducciones para las que el proyecto cuente con autorización/licencia correspondiente.

## Estado

Proyecto en desarrollo. Primera fase: arquitectura y MVP.
